# Template 6 — Advocacia clássica contemporânea

Landing page jurídica de alto contraste inspirada na referência enviada: preto, dourado e marfim, tipografia editorial, retratos profissionais e composição institucional. O conteúdo e a marca são demonstrativos e originais.

## Personalização

Edite `src/config/template.config.js` para alterar marca, profissional, OAB, contatos e localização. Edite `src/modules/home/pages/HomePage.jsx` para adaptar Áreas, textos, etapas e perguntas frequentes. Troque as imagens externas por fotografias autorizadas antes da publicação.

## Estrutura

- navegação responsiva;
- hero com proposta de valor e dois CTAs;
- diferenciais e pilares de confiança;
- apresentação do escritório;
- formulário de primeiro contato;
- oito Áreas de atuação;
- processo em quatro etapas;
- perfil profissional e OAB;
- FAQ, CTA final, WhatsApp e rodapé ético.

## Executar

```bash
npm install
npm run dev
```

Execute `npm run lint` e `npm run build` antes de publicar. Todos os contatos, a OAB e as imagens atuais são demonstrativos.
